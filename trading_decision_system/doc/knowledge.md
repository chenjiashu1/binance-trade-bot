* 单纯依赖“价格高低”判断的优缺点
```
优点：
简单直观、可能找到大机会、提供心理安慰。


缺点：
认知陷阱：强化了“便宜=机会”的直觉，尤其对meme币，其价格没有内在价值支撑，低价可能只是泡沫破灭的过程。
锚定效应：你会不自觉地用“历史最高价”来对比，产生“已经跌了95%，还能跌到哪去”的错误想法，导致过早、过重仓位。
忽略趋势：这是最致命的缺点。“下跌趋势中的低价”和“上升趋势中的回调”有本质区别。在下跌趋势中抄底，如同徒手接飞刀。价格可以长期在低位徘徊甚至继续下跌。
缺乏进出场规则：它只回答了“可能在哪买”，但无法告诉你“何时确认买”、“错了怎么办”、“对了何时卖”，不是一个完整的策略。
请记住：市场不会因为“价格低”就自动上涨。它上涨是因为买盘超过了卖盘。我们的工作是发现买盘开始占优的那个时刻，而不是在买盘出现之前就押注它一定会来。

第一步：识别“低价区”，建立观察清单
第二步：等待“需求出现”的证据（关键步骤）---核心是卖盘枯竭，买盘介入
第三步：制定“如果-那么”计划

```
* 布林带:
```
主要依赖于历史价格数据来计算当前价格的波动范围，它能够显示价格相对于布林带上下轨的位置，但无法准确预测未来价格的方向或幅度。换句话说，布林带只能提供当前市场波动性的情况，无法预示市场将如何继续发展。因此，仅依赖布林带来做交易决策可能会导致误判，尤其是在价格剧烈波动时。在没有明确趋势的横盘整理市场中，布林带可能会产生误导性的信号。由于布林带的上下轨在横盘市场中会频繁接触价格，可能导致交易者频繁进出市场，从而增加了交易成本和风险。这种市场条件下，布林带的信号并不总是可靠，可能会出现“假突破”或“假回调”，给交易者带来不必要的损失。
因此，布林带最有效的应用方式是与其他技术指标结合使用，例如相对强弱指数（RSI）、MACD、支撑/阻力位等。通过结合多个指标，您可以更全面地评估市场情况，减少布林带单独使用时可能出现的误导性信号。例如，布林带可能显示价格接近上轨，但若RSI未达到超买区，价格可能仍会继续上涨。因此，将布林带与其他技术分析工具结合使用，能够帮助您做出更准确的交易决策。
```

*  RSI: 
```
RSI数值范围：0～100，常用週期：14日，核心作用：判断市场是否进入超买或超卖状态。RSI从超买区跌破70，可视为放空讯号
，RSI从超卖区突破30，可视为买进讯号。虽然 RSI 只有一条曲线，但可以透过不同週期得RSI组合，达成黄金交叉与死亡交叉判断：
黄金交叉：短週期 RSI 上穿长週期 RSI → 看多信号
死亡交叉：短週期 RSI 下破长週期 RSI → 看空信号
```

* MACD:
```
MACD（Moving Average Convergence Divergence，中文常译为“指数平滑异同移动平均线”）是一种广泛应用于技术分析中的趋势跟踪动量指标，主要用于判断股票、期货、外汇等金融资产的价格走势和买卖时机。
一、MACD 的构成
MACD 通常由三部分组成：

1. MACD 线（快线）：  
   计算公式为：  
   text{MACD线} = text{12日EMA} - text{26日EMA} 其中 EMA 是“指数移动平均”（Exponential Moving Average）。

2. 信号线（Signal Line，慢线）：  
   是 MACD 线的 9 日 EMA：  
   
   text{信号线} = text{MACD线的9日EMA}
   

3. MACD 柱状图（Histogram）：  
   表示 MACD 线与信号线之间的差值：  
   
   text{柱状图} = text{MACD线} - text{信号线}
     
   柱状图在零轴上方为正（通常显示为绿色或红色向上），下方为负（向下）。

二、MACD 的常见用法

1. 金叉与死叉：
   - 金叉（买入信号）：当 MACD 线从下方向上穿过信号线。
   - 死叉（卖出信号）：当 MACD 线从上方向下穿过信号线。

2. 零轴上下判断趋势：
   - MACD 线在零轴上方：通常表示多头市场（上涨趋势）。
   - MACD 线在零轴下方：通常表示空头市场（下跌趋势）。

3. 背离（Divergence）：
   - 看涨背离：价格创新低，但 MACD 没有创新低，暗示下跌动能减弱，可能反转上涨。
   - 看跌背离：价格创新高，但 MACD 没有创新高，暗示上涨动能减弱，可能反转下跌。

4. 柱状图变化：
   - 柱状图逐渐放大：趋势动能增强。
   - 柱状图逐渐缩小：趋势动能减弱，可能即将反转。

三、注意事项

- MACD 是滞后性指标（基于历史价格计算），在震荡市中容易产生假信号。
- 建议结合其他技术指标（如 RSI、布林带、成交量等）或价格形态综合判断。
- 不同周期（如日线、周线）的 MACD 信号意义不同，长周期信号通常更可靠。
```
